# 중소기업 위기 대시보드

공개 API로 수집한 24개 지표와 뉴스 762건을 결합해 중소기업 부실의 **선행 신호**를
추적한다. 연체율·폐업률처럼 부실이 발생한 뒤 기록되는 사후지표 대신, 그보다 먼저
움직이는 지표를 찾아 경보 단계로 바꾸는 것이 목적이다.

여기에 **내일채움공제 중도해지 위험**을 시도별로 추정하는 분석을 더했다.

👉 **https://hmson0105.github.io/sme-early-warning/**

## 분석 방법

### 선행 신호 찾기

지표를 **전년동월대비 변화**로 바꾼 뒤 상관을 잰다. 원래 수준값끼리 재면 둘 다
시간에 따라 흐른다는 이유만으로 상관이 높게 나오는 허위상관이 생긴다. 시차는
0~6개월을 모두 시도해 상관이 가장 큰 시차를 보고한다.

확인된 주요 선행 관계는 다음과 같다.

| 지표 | 상관 | 선행 |
|---|---|---|
| 가계대출 연체율 | r = +0.72 | 4개월 |
| 어음부도율 | r = +0.47 | 6개월 |
| 한국은행 기준금리 | r = +0.47 | 6개월 |

### 내일채움공제 해지 위험 추정

지역별 해지 통계는 공개되지 않는다. 공개된 것은 전국 해지 사유별 건수뿐이다.
그래서 두 단계로 나눈다.

1. **전국 실적**에서 무엇 때문에 해지되는지 비중을 구한다
   (총 132,109건 — 핵심인력 귀책 66.2%, 기업 귀책 33.6%, 최대 사유는 '이직에 의한 퇴직' 34.5%)
2. 그 사유에 대응하는 **공개 지역지표**를 1단계 비중으로 가중합한다

| 해지 사유 | 대리지표 | 가중치 |
|---|---|---|
| 이직·창업에 의한 퇴직 | 자발적 이직률 | 55.6% |
| 권고사직 등 기업사유 퇴직 | 비자발적 이직률 | 22.3% |
| 경제적 부담(기업)·폐업·미납 | 연체율·어음부도율 | 22.1% |

가중치를 임의로 정하지 않고 실제 해지 건수에서 끌어온다는 점이 핵심이다.

**이 수치는 해지율이 아니라 해지 위험 추정이다.** 이직률은 공제 가입자가 아니라
지역 전체 사업체를 센 값이고, 전국 사유 비중이 모든 지역에서 같다고 가정한다.
대응하는 공개 지역지표가 있는 사유는 전체의 65.9%이며 나머지는 반영되지 않는다.
순위는 점검 우선순위를 정하는 참고치이지 인과관계의 근거가 아니다.

## 다시 만들기

빌드 도구가 없다. 파이썬 표준 라이브러리만 쓰며, 뉴스 토픽모델링에만
scikit-learn 이 필요하다.

### 1. API 키

한국은행 ECOS 와 통계청 KOSIS 는 무료로 발급된다.
프로젝트 폴더에 `keys.env` 파일을 만들어 넣는다. `.gitignore` 에 등록되어 있어 커밋되지 않는다.

```
ECOS_API_KEY=...
KOSIS_API_KEY=...
```

환경변수로 주어도 되고, 여러 프로젝트가 키를 공유한다면 `~/.config/sme-dashboard/keys.env` 에 두어도 된다. **키를 저장소 안에 두지 않는다.**
공공데이터포털 파일은 키 없이 받으므로 별도 발급이 필요 없다.

### 2. 수집·분석

순서가 있다. `build_index.py` 는 `collect_ecos.py` 의 산출물을 읽고,
`build_nacham.py` 는 앞의 두 수집 결과를 모두 읽는다.

```bash
python3 analysis/collect_ecos.py     # ECOS 22종 + KOSIS 2종 → analysis/ecos_result.json
python3 analysis/build_index.py      # 시차 상관·종합지수     → data/ecos.json
python3 analysis/collect_region.py   # 시도별 산업·신용       → data/region.json
python3 analysis/collect_jobmove.py  # 시도별 이직            → data/jobmove.json
python3 analysis/build_map.py        # 시도 경계 SVG          → data/kmap.json
python3 analysis/build_nacham.py     # 공제 해지 위험 추정    → data/nacham.json
python3 analysis/crawl_topic.py      # 뉴스 크롤링 + LDA      → analysis/topic_result.json
```

### 3. 띄우기

```bash
python3 -m http.server 8139     # http://localhost:8139
```

컴파일도 설치도 없다. GitHub Pages 가 파일을 그대로 서빙한다.

## 알아둘 점

- **ECOS 2차원 통계표**는 항목을 하나만 지정하면 은행 종류가 섞여 같은 월이
  여러 번 나온다. 중복 시점이 나오면 중단하는 검사가 들어 있다.
- **KOSIS 는 4만 셀 제한**이 있다. 차원이 많은 표는 거부된다.
- 중소기업 **전용** 연체율은 전국 단위 표에 없고 지역별 표에만 있다.
- 지역 지표는 모두 **최근 6개월 평균**을 쓴다. 단월 값을 쓰면 어음부도율이 한 달
  튀는 것만으로 순위가 뒤집힌다(광주 2026.07 0.12% → 08 2.59%).
- `build_map.py` 는 7.5MB GeoJSON 을 한 번 내려받아 캐시하고 약 42KB 로 줄인다.
- 상관은 인과가 아니다. 결과는 탐색적·가설 수준으로 읽어야 한다.
