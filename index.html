    분석 결과

    최다 사유는 '이직에 의한 퇴직'(—). 귀책 기준으로 핵심인력 —, 기업 —

    내일채움공제

    시도별 해지 위험 추정

    지역별 해지 통계는 미공개. 상기 사유 비중을 가중치로 적용하여 대응 공개지표를 결합. 실제 해지율이 아닌 추정치

    분석 결과

    —

    가중치는 임의 설정이 아님. 실제 해지 건수에서 각 사유가 차지하는 비중을 그대로 적용. 지역지표로 설명 가능한 사유는 전체의 —, 나머지(개인 사정·학업 등)는 미반영

    ※ 이직률은 공제 가입자가 아닌 지역 전체 사업체 기준. 전국 사유 비중이 전 지역에 동일하다고 가정. 순위는 점검 우선순위 참고치
    내일채움공제

    활용 방안 3가지

    • 01위험 상위 지역 선제 안내 만기 혜택 및 중도해지 시 손실을 사전 안내
      해지 사유 1위가 이직이므로 안내 대상에 근로자 본인 포함 필요
    • 02귀책 유형별 대응 분리 기업 재무 악화 지역은 정책자금·경영지원과 연계
      이직 다발 지역은 재직 유인 강화에 집중
    • 03월 단위 모니터링 체계 전 지표가 월 단위 공개 API이므로 스크립트 재실행만으로 갱신
      분기·연 단위 집계 대비 변화 감지 시점 단축
    정리

    확인 사항 4건

    01

    금융지표가 선행

    어음부도율·기준금리가 연체율에 약 6개월 선행. 체감지표·생산 실적보다 반응 신속

    02

    체감지표는 방향으로 판단

    중소기업 BSI는 전 기간 기준선 하회. 절대값 기준 경보 설정 시 상시 발령

    03

    전체 안정, 연체 미해결

    종합지수는 안정 구간이나 연체율은 저점의 3배 수준. 금리 하락에도 동반 하락 없음

    04

    공제 해지는 인력 이동이 주원인

    해지의 3분의 2가 근로자 측 사유, 1위는 이직. 기업 재무만으로는 포착 불가

    정리

    활용 범위와 한계

    가능

    점검 대상 지역·업종의 우선순위 설정. 동일 기준으로 매월 재산출되므로 변화 추적 가능

    불가

    개별 기업의 부실 여부 판단 불가. 전 자료가 지역·전국 단위 집계

    유의

    동행은 인과가 아님. 관측 기간에 코로나·금리 급변·통상 마찰이 모두 포함되어 평시 지속 여부는 미검증

    방법

    산출 절차 4단계

    • 1전년 동월 대비로 변환 원계열 간 비교 시 공통 추세만으로 관계가 과대 추정(허위상관). 전년 동월 대비 변화로 전환하여 비교
    • 20~6개월 시차 적용 지표를 월 단위로 이동시키며 연체율과의 최적 지점 탐색. 해당 지점이 선행 기간
    • 3동일 척도로 표준화 %와 지수는 직접 합산 불가. 평균 대비 이격 정도로 환산 후 평균하여 종합 점수 산출
    • 4지역지표는 6개월 평균 적용 단월 값 사용 시 순위 변동 과다. 광주 어음부도율은 2026.07 0.12% → 08 2.59%로 단월 급등
    방법

    AI 코딩 도구 활용 구축

    개발 인력·외부 용역 없이 실무자가 직접 구축. 코드 전량 공개

    • 01수집 한국은행·통계청 API 수집 코드를 대화 방식으로 작성
    • 02오류 해결 동일 월 중복 반환 문제(102개월 구간에서 306건)를 확인하고 중복 검사 추가
    • 03분석 전년 동월 대비 변환, 시차 상관, 종합 점수 산출을 코드로 구현
    • 04화면·배포 본 화면 구현 후 깃허브 게시. 링크만으로 열람 가능
    준비물
